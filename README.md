# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm run test:groups
npm run test:anchors
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。`test:anchors` 覆盖锚定重映射、待修复、稳定子重合像归类与撤销/重做的验收场景。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。
- 工程以 IndexedDB 本地保存；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。

## 对称元素锚定

- 对象面板选择“锚定到对称元素”后，在画布上点击可编辑参考点附近的命名旋转中心、镜线或滑移轴即可建立锚定记录；元素按平移晶格分数坐标命名（如 `r:4:0:0`、`g:h:0:1/2`），与单元像素尺寸无关。
- 偏移规则：旋转中心锁定参考点、不允许偏移；镜线/滑移轴只允许沿轴偏移。从任意矩阵实例拖动时，位移先映射回唯一源对象，再整体投影回锚定约束；所有轨道像同步满足约束。
- 稳定子重合像识别：当非平凡群元素把整条路径映成自身的晶格平移像（图元精确坐在旋转中心或跨在镜面上）时，渲染、命中测试与导出共享同一套陪集等价类与规范实例键，同一批像素只画一次、点击身份唯一，不会叠色变深。
- 群或晶格尺寸变化时，兼容元素按分数键自动重映射并重新投影；无法重映射（如切到 p1 或不兼容群、参考点被删除）的锚定进入 `broken` 待修复状态并给出原因，绝不静默脱离，可重新匹配、解除或通过撤销恢复。
- 锚定记录、待修复原因随工程一起存入 IndexedDB（schema v2，含 v1 旧工程原地迁移；未锚定旧图案行为完全不变），并纳入撤销/重做栈。
