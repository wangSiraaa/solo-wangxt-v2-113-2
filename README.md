# 墙纸群无缝图案本地编辑器

纯前端实现：Svelte + TypeScript + Canvas 2D + gl-matrix，数据保存在浏览器 IndexedDB，不需要服务端。

## 运行

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm run build
npm test            # 铺排 + 锚定全部检查
npm run test:groups # 仅 17 群蒙特卡洛铺排
npm run test:anchors# 锚定/稳定子/迁移验收脚本
```

`test:groups` 对全部 17 个墙纸群做蒙特卡洛铺排检查，确认每个群的陪集基本域在平移晶格下恰好覆盖平面，内部点不重不漏。`test:anchors` 覆盖 p4m 四重中心锚定随单元尺寸保持、pg 滑移轴拖动约束、切群待修复/撤销恢复、稳定子重合去重与 v1 工程迁移。

## 设计要点

- 支持 17 个二维墙纸群：`p1, p2, pm, pg, cm, pmm, pmg, cmm, p4, p4m, p4g, p3, p3m1, p31m, p6, p6m`。
- 平移、旋转、反射和滑移反射都表示为 gl-matrix `mat3`，实例由 `T(n,m) · Cᵢ` 生成；不会通过手工复制几块图形伪造群轨道。
- 基本域逐实例裁切。跨基本域或周期边界的路径仍只有一个源路径，其每个矩阵像分别被裁切。
- 编辑源对象的路径节点、颜色、透明度会同步更新所有实例；对象 `id` 在撤销/重做中保持不变。
- 点选任意实例会记录 `objectId@coset:n,m`，双击或点击“定位到原始对象”可回到唯一源对象。
- **对称元素锚定**：锚定记录把对象的可编辑参考点（包围盒中心或首节点）关联到当前群中*按晶格分数命名*的旋转中心、镜线或滑移轴，规则分 `pin`（与中心精确重合）、`on`（在轴上、可沿轴滑动）、`offset`（固定法向偏移）。从任意矩阵实例拖动都先映射回唯一源对象，再投影到锚定约束；因此 pg 锚到滑移轴后拖镜像，源对象与全部像仍在轴上。改单元尺寸时分数命名元素自动跟随，活动锚定会重新贴合。
- **稳定子重合处理**：渲染、命中测试与导出共用同一套“几何重合分组”（比较变换后路径的去重量化点集，而非矩阵）。把旋转对称图元放在四重中心时，稳定子造成的重合像只绘制/命中一次——不会叠加变深，点击也没有身份歧义；中心附近真正不同的旋转像则照常保留。
- **切群与迁移**：切到 p1 或不含该元素的不兼容群时锚定不删除，而是进入 `broken` 待修复状态并给出原因，可在检查器中修复或解除，撤销可恢复；切回兼容群自动复活。IndexedDB 升级到 v2，旧 v1 工程读取时补出空锚定并迁移；对象 ID 与未锚定旧图案行为保持不变。
- 滑移反射、旋转中心、镜面和透明边缘都有可视化标记；活动锚定的元素会在画布上标亮（选中对象为橙色）；内置滑移、四重旋转、p6m 样例。
- “接缝/导出”页生成透明 PNG 周期单元，并用同一个单元重复 3×3 检查接缝；三角晶格导出 2×2 原胞形成矩形超级周期。
- 工程以 IndexedDB 本地保存（含锚定与待修复原因）；编辑会自动防抖保存，也可 Ctrl/⌘+S 立即保存。
